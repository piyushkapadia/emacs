Keyboard Shortcuts

Verified for this Emacs-style configuration

Notation: ^ means Control, M means Meta (usually Alt), and S means Shift. A sequence separated by “then” is typed in order; for example ^Xthen^F.

The leader chord is M-m (Meta+m). CUA changes are called out explicitly; the refcard’s default meaning does not always apply.

Configured CUA keys: ^A select all, ^F search forward, ^Y redo, ^W cut/kill region, and ^V paste.

In particular, ^Y is redo here, not Emacs’ usual yank. The layer’s ^CthenR opens its search-and-replace prompt.

CUA mode uses Shift-arrow keys for selection. Org's reference-card Shift-arrow actions are disputed and are redirected by org-replace-disputed-keys when that setting is active. This guide therefore omits those Shift-arrow shortcuts; Meta-arrow heading movement remains available.

The agenda, capture, and stored-link keys are global Org bindings verified in the supplied live keybinding dump. Other entries are Org 9.8 mode bindings. The Spacemacs capture alternative is M-mthenCthenC.
